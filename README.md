# CocoaChat · 코코아챗

첫 커리어 커피챗을 준비하는 사람을 위한 해커톤 웹 프로토타입입니다. AI와 대화하며 프로필과 고민을 정리하고, 가상 실무자 추천과 맞춤 질문을 받아 커피챗을 요청합니다. 실무자 화면에서 요청을 검토하고 일정을 잡는 과정부터 채팅, 회고, 커뮤니티 탐색까지 시연할 수 있습니다.

## 전체 워크플로우

| 단계 | 동작 |
| --- | --- |
| 온보딩 | 코코아챗에 현재 상황, 관심 직무, 경험과 고민을 자유롭게 입력합니다. 앱이 내용을 프로필에 정리하고 빠진 항목을 추가로 묻습니다. |
| 추천과 요청 | 사용자가 프로필을 검토하고 공유할 항목을 선택합니다. 가상 실무자를 골라 핵심 질문 3개와 추가 질문 2개를 검토·수정하고, 질문 이유를 직접 작성한 뒤 요청을 보냅니다. |
| 요청 검토와 예약 | 실무자는 `/mentor` 화면에서 요청을 수락하거나 거절합니다. 한쪽이 일정을 제안하고 상대방이 확정합니다. 양측 현지 시간으로 일정을 확인할 수 있고, 일정 없이 바로 시작하는 흐름도 시연할 수 있습니다. |
| 커피챗 | 예약 시간이 되거나 바로 시작을 선택하면 채팅할 수 있습니다. 코파일럿이 후속 질문, 초안 교정, 번역, 직무 용어 설명, 요약을 돕습니다. 제안은 사용자가 확인하고 직접 전송합니다. 양측이 동의하면 가상 실무자 화면에서도 AI 답변 초안을 생성할 수 있습니다. |
| 회고와 커뮤니티 | 커피챗 종료 후 소감을 남기고 감사 메시지 초안을 확인합니다. 진로와 동의한 관심사를 바탕으로 커뮤니티를 추천하며, 참여한 방에서는 호스트가 대화 주제를 제안할 수 있습니다. |

멘토 목록에는 가상의 인물과 회사 18개 페르소나가 들어 있습니다. 보이스톡·페이스톡은 화면 시연이며 카카오톡 메시지 전송이나 실제 음성·영상 통화는 연동되어 있지 않습니다.

## 시스템 구조와 기술 스택

| 영역 | 기술 | 역할 |
| --- | --- | --- |
| 프런트엔드 | HTML, CSS, Vanilla JavaScript | 반응형 구직자·실무자 화면, 채팅, 추천, 예약, 커뮤니티 |
| 로컬 서버 | Node.js HTTP 서버, Fetch API | 화면과 JSON API 제공, 모델 요청 중계, 두 기기 사이의 신청·예약·대화 동기화 |
| 상태 저장 | 브라우저 `localStorage`, 로컬 JSON | 개인 프로필과 설정은 브라우저에, 링크로 연결한 세션은 Node 서버의 `.local-data/`에 보관 |
| 배포 구성 | Cloudflare Workers, Wrangler, D1용 SQL | 서버와 정적 자산을 Worker용으로 빌드합니다. 별도 호스팅용 세션 처리기에 D1 스키마가 포함되어 있으며, 기본 Wrangler 구성에는 D1 바인딩이 설정돼 있지 않습니다. |
| 빌드와 검증 | Node.js 스크립트, npm, 테스트 스크립트 | HTML·CSS·JS와 프롬프트를 Worker에 묶고, 오프라인 HTML도 생성합니다. |

## API와 외부 연동

| API 또는 데이터 소스 | 사용 방식 |
| --- | --- |
| OpenAI Responses API · `POST /v1/responses` | 서버에서 온보딩 정보 정리, 맞춤 질문, 공개 프로필 요약, 코파일럿, 가상 실무자 답변 초안을 생성합니다. 응답은 JSON으로 요청하고 `store: false`를 설정합니다. 모델은 `OPENAI_MODEL`로 지정할 수 있습니다. |
| Google News RSS | 뉴스 활용에 동의한 경우 주제에 맞는 제목, 매체, 날짜, 링크를 조회해 커뮤니티의 대화 질문을 만듭니다. 기사의 본문 요약 기능은 포함되어 있지 않습니다. |
| 앱 내부 JSON API | `/api/mentors`는 예시 멘토 카탈로그, `/api/questions`는 질문 준비, `/api/profile-summary`는 공개 프로필 요약, `/api/assistant`는 AI 대화 기능, `/api/community-topic`은 호스트의 화두 생성을 처리합니다. 로컬 기기 연결에는 별도의 세션 API를 사용합니다. |

`OPENAI_API_KEY`는 서버의 `.env.local` 또는 실행 환경 변수에 설정합니다. 대화 내용이 필요한 AI 기능은 양측의 대화 분석 동의를 확인하며, 초안 교정처럼 대화 기록이 필요 없는 기능은 사용자의 초안을 처리합니다.

## 실행 방법

Node.js 24를 기준으로 저장소 루트에서 실행합니다.

```bash
npm run dev
```

- 구직자 화면은 `http://localhost:4173`, 실무자 화면은 `http://localhost:4173/mentor`에서 열립니다.
- API 키 없이도 기본 시연이 가능하며, 이때 AI 기능은 규칙과 예시 응답을 사용합니다. 실제 AI 기능을 쓰려면 [`.env.example`](.env.example)을 참고해 로컬 환경을 설정합니다.
- 같은 Wi-Fi의 두 기기에서 시연하려면 앱에서 실무자 연결 링크를 생성하고 다른 기기에서 엽니다.
- `node scripts/offline.mjs`를 실행하면 브라우저에서 바로 열 수 있는 `outputs/coffeebean-demo.html`이 생성됩니다.
- `npm test`로 요청·예약·기기 연결·AI 응답 계약 등의 테스트를 실행할 수 있습니다. 상세 시연 순서는 [RUNBOOK.md](RUNBOOK.md)를 참고하세요.
